# Меню: обліковий запис і управління сайтом

Адміністрування та API більше не стоять у тому самому меню, що пошта, простір і міст ШІ.

- Облікове меню (Мій простір і решта сервісів) показує користувацькі пункти. Налаштування облікового запису й «Міст ШІ → сайт» лишаються там. Адміністрування та API з цього меню прибрано, разом із копіями їхніх сторінок.
- Коли в цій вкладці увімкнено технічний профіль, смуга зверху має «Адміністрування», «API» і «Обліковий запис». На сторінках управління бічне меню містить лише ці два розділи.
- Пряма адреса адміністрування чи API без увімкненого технічного профілю відкриває двері: увімкнути профіль або повернутися до облікового запису. Консоль до цього не показується.
- Перемикач «лише в активному технічному профілі» для самих дій сервера цей випуск не вмикає.

## Після аудиту вмісту (14.10)

Управління сайтом, що жило всередині користувацьких служб, теж іде за технічний профіль (докладно: `deploy/AUDIT-BEHEER-OPPERVLAK.md`):

- Міст ШІ → сайт: «Панель розгортання», «Додатки» (на сервері) та «Архів на ПК» зникають з меню й вкладок без технічного профілю; пряма адреса (і dashboard.tarasevych.com) відкриває двері. Смуга профілю має кнопку «Розгортання».
- Агенти: «Доступ ШІ за підписом», «Цей сервер» і таблиця перемикачів дверей — лише з технічним профілем.
- Налаштування → Вхід: право passkey схвалювати оновлення сервера більше не показується; воно в Адміністрування → Оновлення.
- Hub: прибрано мертву адміністративну панель із керуванням користувачами.
