# Розгортання: термінал у браузері (етап C)

Дата: 2026-10-13. Коміт збірки — файл `BRON-COMMIT` усередині архіву `mijn-ruimte-<версія>.tar.gz`.
Версія архіву має вигляд `YYYYMMDD-HHMMSS` (наприклад `20261013-173000`): інсталятор приймає лише цей шаблон (`^[0-9]{8}-[0-9]{6}$`).

Термінал **вимкнений**, доки ви самі не ввімкнете його на пристрої. RLS лишається в режимі аудиту (`afdwingen=uit`). OPA лишається в тіні. Цей випуск не вмикає SSH CA, Guacamole, SIEM і feature flags.

## Що це

Командний рядок у тимчасовому контейнері на **вашому** пристрої (агент 0.6.0), не на хості сайту.
Контейнер: rootless Podman, `--network none`, `--cap-drop ALL`, `no-new-privileges`, `--read-only`, ліміт пам’яті 512 МБ.
Обрана тека монтується як `/werk` (за замовчуванням лише читання). Секретні місця (`.ssh`, `.env`, ключі) накриті tmpfs або `/dev/null`.
Вивід сесії пишеться як asciicast v2 (gzip, до 4 МБ). Введення не зберігається. Запис бачать ролі «Аудитор» і «Власник» (`opnames.bekijken`).

## Увімкнути на сервері «Mijn Ruimte»

Після встановлення цього випуску (міграція `0036_terminal_sessies.sql` створює таблицю сесій):

```bash
sudo /usr/local/sbin/mijn-ruimte-installeer apps-terminal on
```

Вимкнути:

```bash
sudo /usr/local/sbin/mijn-ruimte-installeer apps-terminal off
```

Команда вимагає root і вже налаштованого агента додатків (`apps-inrichten` і `apps-koppelen`). Вона виконує від користувача `mr-apps`:

```bash
node agent.mjs terminal-config on --runtime podman
```

і перезапускає `mijn-ruimte-apps-agent.service`. Без цього кроку кнопка «Термінал» у технічній смузі не має пристроїв.

На іншому своєму комп’ютері (не сервер сайту), у каталозі агента:

```bash
node agent.mjs terminal-config on --runtime podman
# тестова машина (відкриває лише роль terminal.test):
node agent.mjs terminal-config on --runtime podman --test
node agent.mjs terminal-config off
```

Потім перезапустіть `node agent.mjs run`.

## Як відкрити сесію на сайті

1. Увійдіть і увімкніть технічний профіль у **цій** вкладці (підтвердження входу, причина, термін).
2. Роль «Адміністратор» має `terminal.servers` (термінали серверів). Роль «Розробник» має `terminal.test` (лише машини з `--test`). Власник має обидві.
3. У жовтій смузі: «Термінал» (на телефоні спершу «ще», кнопка `meer`).
4. Оберіть пристрій, теку зі списку дозволених коренів агента, хвилини (не більше 60), причину (щонайменше 3 символи). Запис у теку — окремий прапорець; теки `--readonly-root` лишаються лише для читання.
5. «Відкрити» ще раз підтверджує вхід (stap-op). Браузер з’єднується з `wss://<хост>/terminal/ws`. Квиток живе 30 секунд і передається лише в першому повідомленні, не в адресі.

Одночасно не більше двох живих сесій на користувача. Сесія закривається в кінці терміну, коли закриваєте вікно, або коли контейнер завершується.

## Чого цей випуск не робить

- Не вмикає термінал сам.
- Не відкриває порт назовні і не дає оболонку на хості (shells лишаються забороненими в агенті).
- Не переводить RLS у `afdwingen=aan` і не вмикає OPA fail-closed. Це лише після статистики тіньових лічильників на живому сервері.
- Не містить SSH-сертифікатів, Guacamole (RDP/VNC), експорту в SIEM і таблиці feature flags. Вони лишаються наступними етапами і теж мають бути вимкнені за замовчуванням.
