# План: розширення браузера «Mijn Ruimte» і доступ ШІ до сайту

Мета: користувач вмикає в кабінеті один перемикач, ставить розширення з сайту, і його ШІ-агенти (Claude через наш MCP-конектор) можуть читати сторінки сайту й діяти в них. Без ручних налаштувань і без коду. Розширення працює **лише на нашому сайті**.

## Принципи безпеки
- Розширення Manifest V3, `host_permissions` лише `https://*.tarasevych.com/*`. На інших сайтах воно нічого не бачить і не робить.
- Доступ керується з кабінету: вимкнено типово, рівні (читання / навігація / дії зі змінами), відкликання одним кліком.
- Дії зі змінами завжди через запит «Дозволити» на сайті (як `fs.write` та `docker.manage`).
- Кожна дія в журналі, який бачить користувач. Ізоляція користувачів така сама, як у конекторі пристроїв (RLS, `userId` лише з сесії).
- Вміст сторінок для моделі позначається як недовірений (як `untrusted()` в `connectors-hulpmiddelen.ts`).

## Архітектура (повторне використання того, що вже є)
1. **Парування**: код з кабінету → розширення (як `agent pair`). Новий вид агента `browser` у таблиці `agents`.
2. **Канал**: WSS `/agent/ws` (вже є, 4401 без автентифікації). Фонова сторінка розширення тримає з'єднання, контент-скрипт виконує дії на сторінці.
3. **Команди**: `browser.snapshot` (текст і доступні дії), `browser.navigate` (лише наші адреси), `browser.invoke` (виклик оголошеної дії), `browser.click`/`browser.type` (за назвою, лише з підтвердженням). Додаються до `COMMAND_TYPES` і ПЕРЕВІРКА (нова міграція).
4. **MCP-інструменти**: `browser_snapshot`, `browser_open`, `browser_invoke_action` тощо через наявну чергу команд і правила схвалення.
5. **WebMCP**: сайт оголошує свої дії через `navigator.modelContext`, якщо браузер це підтримує. Розширення використовує те саме оголошення, тож дії структуровані, а не «клікання наосліп».

## Встановлення
- Chrome блокує встановлення сторонніх розширень поза магазином. Тому для звичайних користувачів потрібна публікація в Chrome Web Store (unlisted). Це дію має зробити власник (обліковий запис розробника).
- Для розробки й перших тестів: ZIP із сайту → «Load unpacked» у режимі розробника.
- Сторінка в кабінеті: кнопка «Завантажити розширення», покрокова інструкція, статус «розширення підключено».
