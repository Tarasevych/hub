# Публікація розширення «Mijn Ruimte» у Chrome Web Store (для встановлення в один клік)

Chrome не дозволяє встановлювати сторонні розширення «одним кліком» поза магазином (режим розробника, примусове встановлення через політики працює лише на керованих комп'ютерах, а прапорець `--load-extension` прибрано з Chrome 137). Єдиний справжній «в один клік» це Chrome Web Store. Усе нижче готове, потрібен лише акаунт розробника власника сайту.

## Що зробити власнику
1. Зареєструвати акаунт розробника Chrome (одноразово 5 USD): https://chrome.google.com/webstore/devconsole
2. Завантажити `https://mcp.tarasevych.com/downloads/mijn-ruimte-extension.zip` (або зібрати `node scripts/bouw-extensie.mjs`).
3. Видимість: **Unlisted** (доступ за посиланням). Зібрати текст з розділів нижче.
4. Після схвалення скопіювати URL сторінки розширення у файл `extension/store-url.txt` (один рядок), закомітити й розгорнути. Сайт сам покаже кнопку «Встановити з Chrome Web Store» (читає `extension-version.json`), а помічник-файл лишиться запасним варіантом.

## Опис для магазину
**Назва:** Mijn Ruimte
**Короткий опис:** Дозволяє вашому ШІ-помічнику (через конектор Mijn Ruimte) читати й обслуговувати ваші сторінки на tarasevych.com лише з вашого дозволу.
**Докладно:** Розширення працює виключно на tarasevych.com. Нічого не збирає про інші сайти. Ви самі вмикаєте ШІ для свого браузера на сайті та обираєте, які можливості дозволені: читання сторінки, діагностика, вкладки, прокручування, навігація, кліки, введення, вибір у списках, клавіші, дії сайту, знімок екрана. Дії зі змінами завжди чекають вашого «Дозволити». ШІ працює лише поки ви ввійшли на сайті.

## Обґрунтування дозволів (для перевірки магазином)
- `host_permissions: https://*.tarasevych.com/*`: читання й керування сторінками власного сайту користувача, у т. ч. список вкладок і знімок екрана вкладки цього сайту. Інших сайтів розширення не бачить.
- `storage`: зберігає токен підключення (його не видно сторінкам).
- `alarms`: щохвилини перевіряє, чи живе з'єднання (service фоновий обробник засинає).
- `optional_permissions: debugger`: **необов'язковий**. Chrome не приймає цей дозвіл як необов'язковий (запит завжди дає «Лише permissions specified in  manifest may be requested»), тому в пакеті з магазину глибока діагностика через CDP недоступна; для неї є окремий пакет `mijn-ruimte-extension-diagnose.zip` поза магазином, де `debugger` стоїть у `permissions`. У будь-якому разі налагоджувач доступний лише в технічному профілі, лише на адмін-сторінках власного сайту й лише за активного підписаного розблокування; вміст і заголовки запитів не читаються.
- Віддалений код: немає (весь код у пакеті). Дані не продаються й не передаються третім особам.

## Політика конфіденційності (коротко, для сторінки магазину)
Розширення передає на сервер mcp.tarasevych.com лише те, що користувач дозволив своєму ШІ-помічнику, і лише у відповідь на його команди (зміст відкритої сторінки tarasevych.com, список її вкладок, знімок за окремим дозволом). Паролі й платіжні поля не читаються і не заповнюються. Токен підключення зберігається локально в браузері й відкликається кнопкою «Відключити» на сайті.
