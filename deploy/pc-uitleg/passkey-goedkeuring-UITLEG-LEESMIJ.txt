==============================================================================
УКРАЇНСЬКА
==============================================================================

ЩО ЦЕ
- Агенти й помічники можуть лише ПІДГОТУВАТИ оновлення сайту (завантажити пакет). Вони не можуть
  його встановити.
- Встановлюється пакет лише тоді, коли ви на сторінці admin.tarasevych.com -> «Оновлення» натиснете
  «Схвалити й встановити» і підтвердите passkey на телефоні (відбиток пальця, обличчя або PIN).
- Сервер (root) сам перевіряє підпис passkey. Навіть якщо сайт буде зламано, без вашого телефона
  нічого не встановиться.
- Старий спосіб (пакет, підписаний ключем на ПК, див. UITLEG-LEESMIJ.txt біля uitrol-sleutel) працює й далі.

ЯК СХВАЛИТИ ОНОВЛЕННЯ
1. Відкрийте admin.tarasevych.com -> «Оновлення» (на телефоні або на ПК поруч із телефоном).
2. У розділі «Чекають схвалення» перевірте: хто підготував, коміт, тести, що змінено, розмір.
3. «Схвалити й встановити» -> підтвердіть на телефоні. Схвалення діє 5 хвилин і лише для цього пакета.
4. За кілька хвилин у розділі «Історія» з'явиться «Встановлено» (або причина відмови; у разі
   помилки сервер сам повертає попередню версію).
Не впевнені -> «Відхилити».

ПЕРШИЙ PASSKEY (один раз)
1. «Оновлення» -> «Мої passkey для схвалення» -> назва (наприклад «Телефон») -> «Додати passkey».
   Сайт попросить додаткове підтвердження (код з автентифікатора або повторний вхід Google).
2. Сторінка покаже ВІДБИТОК (групи по 4 символи) і команду для SSH.
3. На сервері через SSH: sudo mijn-ruimte-passkey wachtend  - звірте відбиток з телефоном;
   потім: sudo mijn-ruimte-passkey toevoegen <перші 16 або більше символів відбитка>.
4. Увімкнути: у /etc/mijn-ruimte/mcp-rechten.json поставити "passkey-goedkeuring": true.
Наступні passkey (другий телефон, ноутбук) підтверджуються вже доданим passkey, без SSH.
Порада: майте щонайменше два passkey.

КОМУ ДОЗВОЛЕНО ГОТУВАТИ
«Оновлення» -> «Кому дозволено готувати оновлення»: акаунт, токен агента або MCP-підключення,
на 1-30 днів. «Відкликати» діє одразу. Схвалити не може ніхто, крім вас.

ЯКЩО ТЕЛЕФОН ВТРАЧЕНО
- Є інший passkey: «Мої passkey» -> «Видалити» біля втраченого, підтвердити іншим passkey.
- Іншого немає: через SSH  sudo mijn-ruimte-passkey lijst,  потім
  sudo mijn-ruimte-passkey verwijderen <відбиток>   або   sudo mijn-ruimte-passkey alles-intrekken.
- Вимкнути все: "passkey-goedkeuring": false у /etc/mijn-ruimte/mcp-rechten.json.
Passkey зберігається в телефоні (або в iCloud/Google), не на дисках T:\ чи R:\ і не на сервері
(на сервері лише публічна частина).

==============================================================================
NEDERLANDS
==============================================================================

WAT IS DIT
- Agents en helpers kunnen een update van de site alleen VOORBEREIDEN (een pakket uploaden). Ze
  kunnen hem niet installeren.
- Een pakket wordt pas geïnstalleerd als u op admin.tarasevych.com -> «Updates» op
  «Goedkeuren en installeren» drukt en met de passkey op uw telefoon bevestigt (vingerafdruk,
  gezicht of pincode).
- De server (root) controleert de passkey-handtekening zelf. Ook als de site gekraakt wordt,
  wordt zonder uw telefoon niets geïnstalleerd.
- De oude manier (pakket ondertekend met de sleutel op de pc, zie UITLEG-LEESMIJ.txt bij
  uitrol-sleutel) blijft werken.

EEN UPDATE GOEDKEUREN
1. Open admin.tarasevych.com -> «Updates» (op de telefoon, of op de pc met de telefoon erbij).
2. Controleer onder «Wachten op goedkeuring»: wie het voorbereidde, commit, tests, wat er
   verandert, grootte.
3. «Goedkeuren en installeren» -> bevestig op de telefoon. De goedkeuring geldt 5 minuten en
   alleen voor dit pakket.
4. Na enkele minuten staat onder «Geschiedenis» «Geïnstalleerd» (of de reden van weigering; bij
   een fout zet de server zelf de vorige versie terug).
Twijfel -> «Afwijzen».

DE EERSTE PASSKEY (eenmalig)
1. «Updates» -> «Mijn passkeys voor goedkeuring» -> naam (bijvoorbeeld «Telefoon») -> «Passkey
   toevoegen». De site vraagt extra bevestiging (code uit de authenticator-app of opnieuw Google).
2. De pagina toont een VINGERAFDRUK (groepjes van 4 tekens) en de SSH-opdracht.
3. Op de server via SSH: sudo mijn-ruimte-passkey wachtend  - vergelijk de vingerafdruk met de
   telefoon; daarna: sudo mijn-ruimte-passkey toevoegen <eerste 16 of meer tekens>.
4. Aanzetten: in /etc/mijn-ruimte/mcp-rechten.json "passkey-goedkeuring": true zetten.
Volgende passkeys (tweede telefoon, laptop) bevestigt u met een bestaande passkey, zonder SSH.
Advies: zorg voor minstens twee passkeys.

WIE MAG VOORBEREIDEN
«Updates» -> «Wie mag updates voorbereiden»: account, agenttoken of MCP-koppeling, voor 1-30
dagen. «Intrekken» werkt meteen. Goedkeuren kan niemand behalve u.

TELEFOON KWIJT
- Nog een andere passkey: «Mijn passkeys» -> «Verwijderen» bij de verloren passkey, bevestigen
  met de andere passkey.
- Geen andere: via SSH  sudo mijn-ruimte-passkey lijst,  daarna
  sudo mijn-ruimte-passkey verwijderen <vingerafdruk>   of   sudo mijn-ruimte-passkey alles-intrekken.
- Alles uit: "passkey-goedkeuring": false in /etc/mijn-ruimte/mcp-rechten.json.
De passkey staat in de telefoon (of in iCloud/Google), niet op T:\ of R:\ en niet op de server
(daar staat alleen het publieke deel).
