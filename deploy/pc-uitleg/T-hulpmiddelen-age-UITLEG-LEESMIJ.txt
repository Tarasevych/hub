ЩО ЦЕ
- age\age.exe, age\age-keygen.exe - офіційна програма шифрування age v1.3.2 для Windows
  (github.com/FiloSottile/age). Справжність перевірено: контрольна сума з GitHub і підпис

- СЕКРЕТНОГО ключа тут НЕМАЄ і не повинно бути. Він лише в
  R:\mijn-ruimte-reservekopie\sleutels\herstelsleutel-age.txt (+ ваші офлайн-копії).

ЧИ ПОТРІБНО?  ТАК для відновлення. Якщо програму втрачено - завантажте знову з GitHub
і перевірте контрольну суму.

WAT IS DIT
- age\age.exe, age\age-keygen.exe - officieel versleutelprogramma age v1.3.2 voor Windows
  (github.com/FiloSottile/age). Echtheid gecontroleerd: controlesom van GitHub en de
  Sigsum-handtekening (zie VERIFICATIE.txt, SHA256SUMS, *.proof, age-sigsum-key.pub).
- backup-ontvanger.age.pub - PUBLIEKE sleutel (niet geheim). Dezelfde staat op de server in
  /etc/mijn-ruimte/backup-ontvanger.age.pub; daarmee versleutelt de server de back-ups.
- De GEHEIME sleutel staat hier NIET en hoort hier ook niet. Die staat alleen in
  R:\mijn-ruimte-reservekopie\sleutels\herstelsleutel-age.txt (+ je offline kopieen).

WAAROM
- Met dit programma ontsleutel je op de pc de back-ups bij een herstel.

NODIG?  JA voor herstel. Kwijt? Opnieuw downloaden van GitHub en de controlesom nakijken.

VEILIGHEID
- De publieke sleutel mag gezien worden, maar wijzig hem niet zonder reden.
- Zet herstelsleutel-age.txt hier nooit neer.
