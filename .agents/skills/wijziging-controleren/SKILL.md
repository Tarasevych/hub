# Перевірка змін Mijn Ruimte

## Призначення

Використовуй навичку, коли власник або агент просить перевірити готовність, знайти помилки, оцінити безпеку, випробувати нову можливість, звірити міграції чи підготувати висновок перед випуском.

## Порядок

1. З'ясуй, які саме файли й правила змінено, які служби вони зачіпають та з якої основи походять. Без перевіреної основи висновок про готовність випуску не давай.
2. Перевір, що чинні правила та інструменти координації не були обійдені. Перевір результат відбитка правил і походження архіву, якщо йдеться про випуск.
3. Запусти відповідні випробування, якщо виконання дозволене середовищем: перевірки типів, модульні випробування, пов'язані випробування служб і збірку. Назви точні команди й фактичні результати.
4. Для сторінок перевір різні розміри екрана, зокрема вузький телефон, прокручування, сенсорні елементи, клавіатурне керування й обидві мови.
5. Для серверних змін перевір відмову в доступі, розмежування просторів, відсутність секретів у повідомленнях, повторні запити й оброблення збоїв.
6. Для міграцій звір уже застосовані записи, порядок номерів, збереження даних, індекси, правила доступу та відновлюваність. Не перезаписуй нез'ясовані міграції.
7. Проведи обов'язкову 15-пунктову архітектурну перевірку за маніфестом «Плющ» (`AGENTS.md` §3б, §10.4–§10.5, навичка `klimop-architectuur`): відсутність нової єдиної точки відмови, прихованих повноважень, витоку метаданих, примусових витрат ресурсів чи ризику для всієї мережі через один з'єднувач, відсутність 14 заборонених спрощень та збереження чинної робочої інфраструктури без самовільних змін.
8. Відокремлюй підтверджений успіх, підтверджену ваду, попередження та невиконану перевірку. Невиконані перевірки не зараховуй до успішних.
9. Передай відомості тому самому конвеєру розробки й випусків. Погодження власника не можна замінити позитивним звітом перевірок.

## Результат

Перелік підтверджених результатів, відповідність 15 питанням архітектурної перевірки «Плющ», ризики за серйозністю, відомості про середовище, невиконані випробування та рішення «можна передавати» або «потрібне виправлення». Жодного самостійного встановлення.
