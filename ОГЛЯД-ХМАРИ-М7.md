# Повна інтеграція Хмари M7 (Повна інтеграція Хмари M7) · Набір розробки з пріоритетом безпеки

База: M6 DevKit із робочого архіву `20261027-212158` (не підтвердження поточної робоче середовище-версії).

## Перевірка

```bash
node --test tests/eenheid/cloud-*mjs
node scripts/cloud-volledige-uitgave-poort.mjs
node scripts/kaart-controle.mjs --stil
```

Очікуваний результат: модульні тести проходять успішно; шлюз випуску (випуск пропускний бар'єр) повертає `BLOCKED` (код виходу `2`); перевірка карти файлів — без помилок.

**Не встановлювати** в робоче середовище, не оновлювати GitHub `main`/`voornaamst`, не застосовувати міграцій без попередньої перевірки на передпускове середовище. Не вставляти ключ відновлення користувача (користувач відновлення ключ) або вивід WebAuthn PRF у журнал, аналітику, мережевий запит чи серверний HTML.

Опис меж довіри та незакритих питань: [`docs/АРХІТЕКТУРА-ПРИВАТНОСТІ-ХМАРИ-М7.uk.md`](./docs/АРХІТЕКТУРА-ПРИВАТНОСТІ-ХМАРИ-М7.uk.md) ([🇳🇱 NL](./docs/WOLK-M7-PRIVACY-ARCHITECTUUR.nl.md)).
