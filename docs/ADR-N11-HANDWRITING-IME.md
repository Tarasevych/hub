# ADR N-11 — рукописне введення та IME

- Статус: proposed, окремий проєкт
- Поточний N-11: лише локальні інструменти транслітерації, екранна клавіатура та явний вибір UA/NL.
- Рішення: не вбудовувати розпізнавання рукопису в цей деплой і не називати полотно підпису в редакторі документів поштовим IME.

Окремий проєкт має до реалізації визначити: on-device чи server recognition; підтримувані мови й моделі; retention рукописних штрихів; consent і privacy notice; offline/error fallback; accessibility без залежності від жестів; bounded payload і rate limits; threat model для untrusted strokes/model output; метрики точності та owner acceptance.

До проходження цих gates продукт зберігає нативні клавіатуру/IME браузера, а UI прямо повідомляє, що рукописне розпізнавання не ввімкнено.
