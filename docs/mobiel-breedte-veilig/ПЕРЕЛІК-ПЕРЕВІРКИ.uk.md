# Перелік перевірки для Павла — MOBIEL-002 (позначте кожен пункт «працює» або «ні»)

1. Після встановлення в «Прапорцях» є «Безпечна вузька верстка на телефоні» (`mobiel-breedte-veilig-v1`), і вона **вимкнена**. — працює / ні
2. З вимкненим прапорцем сайт на комп'ютері й телефоні виглядає як раніше. — працює / ні
3. Увімкніть прапорець лише для себе й перезавантажте сторінку на телефоні. — працює / ні
4. Відкрийте `/agenten#connectors` на телефоні: сторінка відкривається швидко, не зависає. — працює / ні
5. Адреса лишається `#connectors` і сама не змінюється на `#overzicht` чи інший розділ. — працює / ні
6. Відкрийте `#tokens`, `#toegang`, `#apparaten`: гортаються плавно. — працює / ні
7. Пошта, обліковий запис і «Дім» на телефоні виглядають нормально, нічого не виходить за край екрана. — працює / ні
8. Світла й темна тема, українська й нідерландська — без змін на гірше. — працює / ні
9. Вимкніть прапорець, перезавантажте: усе повертається як було. — працює / ні
