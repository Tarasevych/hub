# Адміністративний міст Identity v1 (Identity Admin Bridge v1)

## Джерело істини
Серверна частина Hub залишається єдиним джерелом істини щодо користувачів, запитів на доступ, ролей, робочих просторів, видалення, відновлення та аудиту.

## Потік виконання (Потік)
1. Автентифікована вкладка Hub створює одноразовий код передачі (`handoff code`) для сервісу `identity`.
2. Код втрачає чинність через дві хвилини й може бути використаний лише один раз.
3. Сервіс Identity обмінює цей код у режимі «сервер — сервер».
4. Hub створює ізольовану для сервісу сеанс з дозволом `identity.profile.read` та, для власника, `identity.admin`.
5. Застосунок Identity зберігає сервісний маркер доступу виключно в `host-only` `HttpOnly` cookie, яка обирається за несекретним ідентифікатором вкладки.
6. Адміністративні мутації в Identity викликають сервісно-адміністративні кінцеві точки Hub, які повторно використовують ті самі бізнес-функції, що й застарілі (застарілий спадок) адміністративні кінцеві точки Hub.

## Ізоляція вкладок (Tab ізоляція)
Кожна вкладка оглядача зберігає у `sessionStorage` лише несекретний ідентифікатор вкладки (`tab ID`). Секретний сервісний маркер доступу зберігається в `HttpOnly` cookie, ім'я якої містить цей `tab ID`. Вихід із системи в одній вкладці Identity відкликає лише цю конкретну сервісну сеанс.

## Безпека
- одноразова передача (`one-time handoff`);
- заборона типово (`deny by default`);
- перевірка прав власника на кожному адміністративному запиті;
- оборотне видалення з можливістю відновлення;
- відкликання всіх сеансів Hub і сервісів під час видалення облікового запису;
- записи аудиту для операцій передача контексту та адміністративних мутацій;
- жодних сервісних маркерів доступу в URL-адресах, `localStorage`, `sessionStorage` або журналах клієнтської частини.

## Повернення стану (Відкочування)
Застарілі (застарілий спадок) адміністративні маршрути серверної частини Hub залишаються доступними. Звичайний інтерфейс Hub більше їх не показує. Параметр `?legacy-admin=1` є аварійною точкою входу для повернення стану виключно для власника.
