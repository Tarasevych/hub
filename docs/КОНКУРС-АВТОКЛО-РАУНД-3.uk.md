# Супровід і матеріали для участі в конкурсі «Built with AutoClaw — Раунд 3» (5–20 листопада 2026)

Цей документ містить повний супровід, технічний опис упроваджених у **Mijn Ruimte** можливостей для агента **AutoClaw (`GLM-5.3-flashX-Legal` / `Z.ai`)**, інструкцію для демонстрації та готові матеріали для участі в кампанії **Built with AutoClaw — Round 3**.

---

## 1. Що інтегровано в систему Mijn Ruimte для AutoClaw (GLM)

1. **Офіційна реєстрація агента `autoclaw` у всіх шарах платформи:**
   - **Фірмове позначення й емблема (`src/merk/merk-register.ts`, `src/merk/merk-tabel.ts`, `extension/merk-agenten.js`):** зареєстровано канонічний ключ `autoclaw` (псевдоніми: `openclaw`, `glm`, `chatglm`, `zhipu`, `zhipuai`, `zai`, `z.ai`, `glm-5.3-flashx-legal`) із фірмовою векторною емблемою Z.ai (`#FFFFFF` на `#2563EB`, контраст понад 5.1:1).
   - **Власна ізольована адреса з'єднувача MCP v2 (`shared/connector-v2/agenten.ts`, `deploy/mcp/server.mjs`):** `https://mcp.tarasevych.com/autoclaw` із повною підтримкою OAuth 2.0 + PKCE (RFC 9728) та розділенням приватного (`_gebruiker`) і технічного (`_beheer`) просторів.
   - **Колірне маркування та розширення оглядача (`shared/markering-agenten.ts`, `extension/markering-agenten.js`):** акцент `groen` (смарагдовий) для візуального позначення вкладки, якою керує AutoClaw у реальному часі.
   - **Оркестрація та криптографічний замок правил (`orchestratie/beleid.json`, `AUTOCLAW.md`):** агент `autoclaw` офіційно внесений до переліку підтримуваних агентів оркестрації (`github_pr`, `mcp`, `zip`, `tar_gz`, `git_patch`) із власним перехідником правил.
   - **Сховище таємниць (`shared/geheimen.ts`):** автоматичне розпізнавання ключів `ZAI_*`, `AUTOCLAW_*`, `ZHIPU_*`, `GLM_*` як облікових даних штучного інтелекту.

2. **Правнича перевірка договорів, знеособлення та реєстр доказів (`shared/ai-bronnen.ts`, `src/agenten/AgentPagina.tsx`):**
   - Функція **`anonimiseerTekst(tekst, lang)`** автоматично знеособлює чутливі реквізити перед передаванням або оприлюдненням: адреси електронної пошти (`[ПРИХОВАНО_ПОШТА]`), банківські рахунки IBAN (`[ПРИХОВАНО_РАХУНОК]`), номери телефонів (`[ПРИХОВАНО_ТЕЛЕФОН]`) та реєстраційні коди ЄДРПОУ / ІПН / РНОКПП / KvK / BSN (`[ПРИХОВАНО_КОД]`).
   - Функція **`bouwBewijsIndex(brieven, lang)`** розбиває договір чи листування на пронумеровані абзаци (`§1, §2…`), перевіряє кожне зобов'язання, строк і суму на **дослівну присутність в оригіналі** (без вигадок і без підміни перекладом), упорядковує хронологічну шкалу подій та формує готовий реєстр доказів у форматі таблиці Markdown.
   - На сторінці **`https://mcp.tarasevych.com/agenten#agent/autoclaw`** додано інтерактивну вкладку **«5. Правнича перевірка й реєстр доказів (GLM-5.3-flashX-Legal)»**, де можна наживо перевірити текст договору чи листа та скопіювати готовий реєстр доказів.

3. **Командний інтерфейс мосту (`.agents/skills/mijn-ruimte/scripts/mijn-ruimte`):**
   - `node .agents/skills/mijn-ruimte/scripts/mijn-ruimte Verbind --url https://mcp.tarasevych.com/autoclaw` — під'єднання AutoClaw до 4-канального мосту.
   - `node .agents/skills/mijn-ruimte/scripts/mijn-ruimte JuridischControleer --taal uk` — миттєва перевірка тексту договору, знеособлення реквізитів і побудова реєстру доказів для `GLM-5.3-flashX-Legal`.
   - `node .agents/skills/mijn-ruimte/scripts/mijn-ruimte AutoClawPakket --taal uk` — виведення повного пакета відомостей для подання заявки Раунду 3.
