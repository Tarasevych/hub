## Перевірено в браузері (живий код)

- 12 секцій у DOM; hash-роутинг перемикає сторінку й заголовок (`#themes` → «Теми»).
- Палітра Violet змінює `--accent` на `#6d5efc` і стан `themes.palette`.
- Перемикач step-up змінює `security.stepup` з `true` на `false`.
- Панель «Стан (JSON)» показує повний зліпок налаштувань — зручно звіряти очікування.

## Що ще потрібно для продакшену

1. Перенести в `src/identity/*` (12 екранів, не один), підключити реальні API.
2. Оновити базу `beleid.json` до `90f0d73`, зареєструвати `IDENTITY-001`.
3. Юніт + e2e (перемикання сторінок, палітри, recovery, сесії), контраст.
4. TRACE-001: журнал + GitHub Release SHA-256, підпис власника, встановлення.
