# Сторінка акаунта — дизайн-специфікація (станом на 2026-11-04)

## Напрям
«Aurora» — світлий, повітряний, з м'якими кольоровими градієнтами фону; картки напівпрозорі (blur), велика типографіка, кольорові плитки іконок за розділами.

## Токени
- Фон: `#f7f8fb` + два radial-градієнти: м'ятний `#d9f5ef` (10%/-10%) і фіолетовий `#e8e3ff` (92%/-8%).
- Чорнило: `#0f172a`; приглушений `#64748b`; лінії `rgba(15,23,42,.08)`.
- Акцент: `#0f9d8a` → `#12b3a0` (градієнт кнопки); м'який `#d7f5ef`.
- Секції: вхід — фіолетовий `#6d5efc`/`#e9e6ff`; безпека — м'ятний; пристрої — синій `#2563eb`/`#dbeafe`; вигляд — бурштиновий `#b45309`/`#fef3c7`; дані — ціан `#0891b2`/`#cffafe`; небезпека — рожевий `#be123c`/`#ffe4e6`.
- Радіуси: картки 24–26 px, рядки 16 px, кнопки 12 px, пігулки 999 px.
- Тіні: `0 1px 2px rgba(15,23,42,.04), 0 12px 32px rgba(15,23,42,.07)`.
- Типографіка: база 15 px; h1 32 px (-.035em); назви розділів 17 px; рядки 14.5 px; підказки 12.5 px.

## Структура
1. Шапка: логотип, крихта, перемикач мови, тема, аватар.
2. Hero: аватар 84 px, ім'я, e-mail, 4 чипи статусу, дві кнопки.
3. Статистика: 3 картки — рівень захисту 78, 3 сесії, 8/10 кодів.
4. Двоколонкова сітка: контент + права колонка (навігація, останні події).
5. Панелі: способи входу, безпека (TOTP + коди), сесії, вигляд, дані, видалення.
6. Небезпека: видалення заблоковане для власника (`OWNER_NIET_WISSEN`).

## Правила кнопок (виправлено після зауваження)
- Десктоп: дії праворуч, `min-width:124px`, висота 34–42 px.
- Мобільні (≤640 px): усі дії — окремим блоком на всю ширину, висота 44 px; бейджі — компактні (`max-content`), не розтягуються; hero-кнопки — сітка 1fr 1fr; сегменти — рівні колонки.
- Причина попередніх «розкиданих» кнопок: у CSS потрапляли літеральні `\n` (PowerShell Replace), через що частина правил відкидалась парсером.

## Живий прототип (2026-11-04)

**Файл:** `account-live.html` — самодостатня сторінка.

- **Фото:** клік по аватару (або hover-камера) відкриває вибір файлу; drag&drop; перевірка типу (PNG/JPEG/WebP) і розміру (4 МБ); прев'ю одразу в трьох місцях (hero, шапка, меню); видалення повертає ініціали.
- **Меню акаунтів:** відкривається з аватара, містить поточний акаунт, ще два акаунти з логотипами Google/Microsoft, «Додати акаунт», «Керувати акаунтами», «Подивитися деталі», «Вийти з усіх». Закриття — клік поза меню або Esc.
- **Деталі:** бічна панель із трьома вкладками (Огляд / Вхід / Сесії) — дані з тих самих джерел, що й сторінка.
- **Живість:** анімації появи меню та панелі, hover-рух карток, плавна зміна теми, ілюстрація щита з плаваючою анімацією, прогрес експорту.
- **Перевірено в браузері:** меню open=true (4 рядки, 4 логотипи), панель деталей open=true (4 пункти), темна тема перемикається, file input і кнопка фото існують.

- Бейджі в мобільному рядку все ще можуть розтягуватись — перевірити після останнього фіксу.
- Потрібне остаточне «так» на стиль, після чого — перенесення в `src/identity/account/` за ТЗ.

## Фото: джерела й керування (2026-11-04)

- Смітничок — **маленька кругла кнопка 24 px** у правому нижньому куті аватара (з'являється на hover/фокус), не перекриває камеру: камера — центр, смітничок — кут.
- Клік по аватару відкриває **діалог «Фото профілю»** з трьома джерелами:
  1. **З пристрою** — drag&drop + вибір файлу (PNG/JPEG/WebP, ≤ 4 МБ);
  2. **З сервісу** — галерея останніх фото Cloud (демо: 4 згенеровані локально);
  3. **За посиланням** — HTTPS-URL зовнішнього джерела.
- Прев'ю і кнопка «Застосувати» активні лише після вибору; «Скасувати»/Esc закривають без змін.
- Перевірено в браузері: діалог `open=true`, 3 вкладки, 4 фото в галереї, застосування дає `img` і `account.photo=true`, смітничок повертає ініціали.
