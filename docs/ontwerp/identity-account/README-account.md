# Акаунт: один актуальний макет (README)

## Актуальний файл — тільки цей

**`identity-live.html`** — **одна сторінка**: усі 12 блоків `identity` йдуть один за одним, ліве меню не перемикає сторінки, а **прокручує до відповідного блоку** (з підсвіткою активного).
Відкрити подвійним кліком. Нічого встановлювати не треба.

## Що в ньому вже враховано (усі ваші зауваження)

- **Одна сторінка:** 12 блоків послідь (Профіль → Ідентичності → Способи входу → Сесії → Безпека → Відновлення → Персоналізація → Теми → Мови → Меню → Віджети → Спільний доступ).
- **Меню — як зміст:** клік по пункту плавно прокручує до блоку; при скролі активний пункт підсвічується сам.
- **14 служб сайту** в тому ж меню; клік по іншій службі дає тост «поза макетом акаунта», а не веде на порожню сторінку.
- Фото: клік по аватару → діалог із трьох джерел (пристрій / сервіс / посилання), прев'ю, «Застосувати».
- Смітничок — маленька кнопка 24 px у куті фото, не перекриває камеру.
- Кнопки: на мобільному — на всю ширину, однакові; бейджі компактні.
- Теми: 4 палітри (Grifel/Puur/Violet/Kleur) + світла/темна/авто.
- Перевірка: панель «Стан (JSON)» показує, що саме змінилося.
- Чесні стани: passkey недоступний, видалення власника заблоковане.

## Як оцінювати

1. Відкрийте `identity-live.html` — усе вже на одній сторінці.
2. Клацніть «Теми» в меню — сторінка прокрутиться до блоку «Теми», пункт підсвітиться.
3. Прокрутіть униз — підсвітка сама перейде на наступний блок.
4. Змініть палітру й тему — переконайтеся, що виглядає доречно.
4. Натисніть на фото — перевірте три джерела й «Застосувати».
5. Розгорніть будь-яку службу (наприклад, Пошта) і клацніть сторінку — побачите заглушку з назвою: меню працює.
6. Відкрийте «Стан (JSON)» — там видно кожне налаштування.
