# Безпечна інтеграція служб перекладу (`UPD-012`)

## 1. Підтримувані служби

У каталозі інтеграцій (`/mappen`) та у налаштуваннях спільних рушіїв (`ai → З’єднання`) підтримуються:
- **Google Translate (Cloud Translation API v2)** — захищений ключ у `owner_vault_v1`, очищення трекерів і таємниць перед відправленням.
- **DeepL (`api-free.deepl.com` / `api.deepl.com`)** — збереження HTML-верстки (`tag_handling`), заголовок `Authorization: DeepL-Auth-Key`.
- **LibreTranslate** — власний або спільний сервер (`POST /translate`) без передачі даних стороннім корпораціям.
- **Власний захищений вузол перекладу** — довільний HTTPS-вузол у приватній мережі власника.

## 2. Чотири режими приватності даних (`privacyModus`)

1. `lokaal-alleen` — переклад виключно локальним ШІ браузера; жодні зовнішні запити не виконуються.
2. `eigen-server` — дозволено лише власний сервер (`LibreTranslate`, `Ollama`, власний захищений вузол).
3. `extern-gezuiverd` *(типовий для зовнішніх служб)* — перед відправленням текст проходить посилене очищення `stripTrackingAndSecrets` (вирізаються маркери стеження, таємні коди, токени та приватні посилання).
4. `extern-volledig` — повний переклад зовнішньою службою лише за явної згоди користувача, прив’язаної до контрольного відбитка `akkoordSleutel` (будь-яка зміна адреси, постачальника чи режиму приватності автоматично скидає старі згоди).

## 3. Захист ключів

Ключі ніколи не зберігаються у відкритому вигляді: вони шифруються в `owner_vault_v1` (`AES-256-GCM`, AAD `owner-vault-v1|<userId>|<keyName>`), вводяться через захищене поле (`GeheimInvoer`) із забороною доступу ШІ (`data-ai-geen-actie`) і перевіряються контрольним реченням без надсилання жодного листа користувача.
