# Макет «Живий дім» — посібник для авторів екранів

Клікабельний макет `huis.tarasevych.com` (HUIS-001, етап 0): один самодостатній HTML-файл на вбудованому мінісимуляторі.
Нормативні джерела — `docs/huis/ДИЗАЙН-МОВА-ЖИВИЙ-ДІМ-20261110.uk.md` і `stijl/hv-tokens.json` (єдине джерело кольорів).

## 1. Структура

| Тека | Що там |
|---|---|
| `stijl/` | `hv-tokens.json` → блок токенів генерує складальник; `basis.css` (скидання, тони, кнопки, папір), `schil.css` (пульт, шапка, навігація), `onderdelen.css` (компоненти `hv-*`), `hemel.css` (небо, герой, розріз, «Дім»), `bladen.css` (аркуші, діалоги, аварійний шар), `gezichten.css` (спеціальні профілі) |
| `gegevens/` | `paspoort.js` (демо-дім), `tarief.js` (ціни на 48 год), `scenarios.js` (15 сценаріїв) |
| `kern/` | `tekst.js`, `opslag.js`, `staat.js`, `gevaar.js`, `handeling.js`, `onderdelen.js`, `grafiek.js`, `hemel.js`, `blad.js`, `schil.js`, `lagen.js`, `pult.js` |
| `schermen/` | `nog-niet.js` (заглушки всіх маршрутів), `thuis.js`, `kamers.js`, `bladen-licht.js`, `gezichten.js` — еталонні модулі; ваш файл кладіть сюди |
| `volgorde.json` | порядок склеювання; `schermen/*` підхоплює новий файл сам |

Назви файлів, функцій, класів і ключів — нідерландською; коментарі — українською або нідерландською.
Кожен файл — `(function (HV) { 'use strict'; … })(window.HV = window.HV || {});` і під час завантаження лише реєструє (жодного DOM).

## 2. Реєстрація

Пізніша реєстрація з тим самим `id` **замінює** заглушку; вкладки зливаються за `id`.

```js
HV.scherm({ id, sectie, titel:[uk,nl], icoon, adres, tabs:[{ id, titel:[uk,nl], adres, render(ctx), verborgen? }], render(ctx) });
HV.tab(schermId, { id, titel:[uk,nl], adres, render(ctx) });           // одна вкладка наявного екрана
HV.blad({ soort, past(apparaat), titel(apparaat), delen:{ bediening(ctx,a), geschiedenis(ctx,a), instellingen(ctx,a) } });
HV.blad({ soort, vrij:true, titel:[uk,nl] | (ctx,id)=>…, icoon, sub(ctx,id), render(ctx,id) });   // вільний аркуш
HV.gezicht({ id, profiel, titel:[uk,nl], render(ctx) });               // обличчя спеціального профілю
HV.actie(naam, (ctx, gegevens, element, gebeurtenis) => …, { kijk | muteert }?); // делегування за data-actie; третій аргумент — §4.2
HV.zijzone(sectie, (ctx) => html);                                     // власний вміст зони «план» на широких екранах (§4.2)
```

- `id` екрана, вкладки, пристрою і `soort` аркуша — лише малі латинські літери й цифри (це частини `location.hash`).
- `ctx`: `{ t, h, p, staat, profiel, rol, taal, dichtheid, route, open(adres), blad(id), meld(…), doe(…) }`.
- `render` повертає **рядок HTML**; дані екрануйте через `HV.h`. Ключ вузла — `data-k="…"` (перерисовка зберігає вузли, фокус і прокручування).
- Маршрут: `ctx.open('energie-tarief')`, `ctx.open('kamers-kamer-woonkamer')`; аркуш: `ctx.blad('apparaat:torsher')`, `ctx.blad('meldingen')`, `ctx.blad(null)`.
  Адреса на справжньому сайті (`/energie/tarief?blad=apparaat:torsher&deel=…`) показується над полотном сама — з `adres` екрана й вкладки.
- Аркуш пристрою: береться останній зареєстрований, чий `past(a)` повертає `true`. Частини, яких ви не дали, малює каркас (`HV.bladDelen.geschiedenis`, `.instellingen`, `.algemeen`).
- Дрібний стан екрана (фільтр, вибрана вкладка): `HV.ui.lees(naam, standaard)` / `HV.ui.zet(naam, waarde)`; у розмітці — `data-actie="ui" data-naam="…" data-waarde="…"`.

## 3. Стан і дії

- Читання: `ctx.staat` (світ) і `HV.kijk.*` — `alle(filter)`, `inKamer(id, filter)`, `soort(s)`, `isAan(a)`, `lampenAan(kamer?)`, `open()`, `temperatuur(kamer)`, `thuis()`, `leeftijd(a)`.
  Пристрій: `{ id, soort, kamer, naam:[uk,nl], mog:[…], st:{…}, beschikbaar:'ok'|'onbereikbaar'|'verouderd'|'verondersteld'|'slaapt', wacht?, maker? }`.
- **Єдина точка дії** — `HV.doe({ doel, mogelijkheid, waarde, door?, stil? })` → `Promise<{ ok, reden?, ongewijzigd? }>` (`ongewijzigd` — команда нічого не змінила, див. 4.3).
  `doel`: id пристрою | `'huis'` | `'alle'` | `'scene:<id>'` | `'kamer:<id>'`. Ворота: зв'язок → доступність → роль → рівень ризику (ритуал) → дозвіл виконавця. Запис у Журналі, знак автора і сповіщення з'являються самі.
- Бажане під час очікування: `HV.gewenst(a, 'helderheid')`; значення словами: `HV.beschrijf(a, mogelijkheid, waarde)`.
- Рівні й дозволи: `HV.gevaar.vind(doel, mogelijkheid, waarde)` → `{ sleutel, niveau, naam, gevolg, risico }`; `HV.gevaar.stand(uitvoerder, sleutel)`; змінити — лише `HV.gevaar.zetStand(…)` (працює тільки для ролі «власник»; для агента такої функції немає). Нову небезпечну чи критичну дію додавайте в `kern/gevaar.js` **з** `gevolg` і `risico` — перевірка без них не проходить.
- Повзунок: `data-schuif="назва"` → обробник отримує `{ waarde, fase:'sleep'|'klaar' }`; під час руху екран не перерисовується, команду надсилайте на `klaar`.
- Сповіщення: `HV.meld({ titel, tekst, gewicht:'info'|'belangrijk'|'alarm', maker, icoon, terug })`; Журнал: `HV.logboek.voegToe({ maker, wat:[uk,nl], waarom, was, werd, soort:'huis.*' })`.

### 4.1. Плитки, знак дії, стани (раунд 2)

- **Форму задає вміст.** `o.tegel(a, { bediening: true })` — для «Обраного» й сторінки кімнати: пристрій з органом рівня (`HV.niveauOrgaan(a)`: яскравість, ціль температури, штори, гучність) стає плиткою з керуванням «−» · `hv-schuif` · «+». Сітка `hv-tegels` дає їй форму 2×2 лише коли колонка не вужча за 224 px (від 700 px полотна колонки й так ≥ 224 px); на телефоні вона займає весь рядок (4×2) і показує число `--hv-getal-m` праворуч (контейнер `tegel`, від 300 px). `vorm:'2x2'` без органа рівня малюється як 2×1 — високої порожньої плитки більше немає. `vorm:'4x2'` — завжди на весь рядок. Повзунок плитки шле команду на `klaar` (дія `tegel-schuif`).
- **Рядок «значення · вік»** складено з неподільних шматків (`.hv-nb`): крапка належить наступному шматку й зникає на початку рядка; назва — до двох рядків без трьох крапок. Для власних плиток — `HV.tegelWaardeRegel([{ html, klas }])`.
- **Знак із ритуалом.** `o.schakel({ ritueel:'gevaarlijk'|'kritiek', actie, … })` — квадрат із подвійною рамкою замість кола; дотик нічого не виконує сам: `HV.doe` відкриває `hv-gevaar`. Рівень у поточному напрямі дає `HV.ritueelVan(a, beeld.schakel)` (стан припущено чи застарів — форма вищого з двох напрямів). `o.tegel` робить це сам: замкнений замок — квадрат, відімкнений — коло. Старе `kritiek:true` з `actie` означає `ritueel:'kritiek'`, без `actie` — пасивний знак (восьмикутника більше немає).
- **Стани.** `staat:'bezig'` — «виконується»: класи з ходом (`HV.gangKlassen`: штори, жалюзі, ворота, двері гаража, замок, клапан) після першої відповіді показують слово напряму й спостережений відсоток (`a.wacht.fase==='bezig'`, `a.wacht.voortgang`), час до «не виконано» — `a.wacht.grens` за класом (`maten.gedrag.wachtPerKlasse`). «Не виконано / niet uitgevoerd» — `HV.mislukt(a)` (контур 2 px `--fout`, `CircleX`, 60 с або до наступної дії).
- **Герой** — власний контейнер `held`: до 600 px — коротке речення, 600–999 — повне речення в одну колонку, від 1000 px — речення й розріз. Розріз-блок «Дому» з'являється сам, коли розрізу в герої немає (контейнер `thuis`). Інші контейнери ядра: `doorsnede`, `nurij` (запис «Зараз важливо»), `kamer`, `kamerlijst`, `tegel`.
- **Небо** стиснуто до героя (`--hv-hemel-einde`), нижче згасає до паперу; на інших сторінках — тихе небо (натяк фази вгорі, далі `--bg`). Штрих опадів живе в герої. На небі — лише `--text` (статична перевірка ловить `--muted` у селекторах неба).
- **Оболонка.** «Команда» — центральний пункт нижньої панелі телефона (плаваючої кнопки немає). На телефоні під шапкою — рядок `hv-sim` 28 px; у шапці — паперова пігулка стиснутого рядка героя і чип важливого (дія `naar-nu`). `o.sim(w)` більше не показує час. `HV.dagstrook(ctx, { kort, makers })` — ряд авторів лише за `makers:true`.

### 4.2. Герой зони, зв'язок, сповіщення, широкі екрани (раунд 3)

- **Герой зони — один для всіх: `o.zoneheld(…)`.** Паперова картка без градієнта: надзаголовок `boven`, речення `zin` (HTML), до чотирьох лічильників **однієї форми** (число 28/600 і підпис 12/600; `toon` фарбує лише число; з `actie` лічильник стає кнопкою) та одна головна дія `actie` (як `o.knop`). Тон зони (`toon`) несуть лише знак і тонка верхня лінія. Власний контейнер `zoneheld`: вузько — лічильники сіткою під реченням, від 720 px — праворуч в один ряд. Власних героїв із градієнтом і власних форм лічильників у файлах екранів не робимо — приклад: «Кімнати → Зараз» (`schermen/kamers.js`).
- **«Немає зв’язку» — це «лише перегляд» для всього, не тільки для `HV.doe`.** Ядро знає вид кожної дії: `kijk` — лише показує (фільтр, вкладка, масштаб) і працює завжди; `muteert` — змінює дім чи пише в Журнал: без зв'язку її орган отримує `aria-disabled="true" data-reden="verbinding"` (це роблять `o.knop`, `o.icoonknop`, `o.chip`, `o.schakel`, `o.segment`, `o.stapper`, `o.schuif`, `o.scene`, `o.stand`), дія не запускається, дотик показує «Не виконано: немає зв’язку з домом». Вид кажіть прямо: `HV.actie('naam', fn, { kijk: true })` або `{ muteert: true }`. Без позначки дію, що сама викликає `.doe(` чи `logboek.voegToe(`, ядро вважає такою, що змінює; решту запускає «на пробу» — якщо вона спробувала писати в Журнал, світ і дозволи повертаються до знімка, а її сповіщення зникають. Для власної розмітки: `HV.orgaanDood(actie)`, `HV.zonderVerbinding()`, `HV.meldZonderVerbinding()`. Виняток — сторінки макета «Система → Симулятор», «Вітрина» і «Складники» (`HV.vrijeTabs`): вони керують макетом і працюють завжди. Діалоги `HV.schil.gevaar` і `herbevestig` без зв'язку не відкриваються; `HV.gevaar.zetStand` відмовляє.
- **Запит «Питати».** `HV.verzoek(id, true)` прибирає запит із «Зараз важливо» лише після `{ ok: true }` від дому; якщо дію не виконано, запит лишається `wacht`, людина бачить причину, у Журналі — «Не виконано: …». Під час виконання `stand === 'bezig'`.
- **Сповіщення.** Показується одне (тривога — першою, інакше найновіше) і лічильник «+N», що веде до центру сповіщень; стосу немає. З «Повернути» воно висить 10 с, важливе — 6 с, звичайне — 4 с (`duur` у `HV.meld` змінює це); те саме сповіщення вдруге не додається. `titel`, `tekst`, `hoe` — рядок або пара `[uk, nl]`. «Повернути» стоїть під текстом. На телефоні з відкритим аркушем сповіщення — один рядок над аркушем.
- **Рейка утримання.** Короткий напис рейки — поле `houd:[uk,nl]` дії в `kern/gevaar.js` («Утримуйте, щоб відімкнути»); без нього — «Утримуйте, щоб підтвердити». Напис завжди один рядок.
- **Клавіатура й історія.** Модальні шари (аварійний, небезпечна дія, Команда, підказка, аркуш на телефоні) тримають фокус самі; аварійний шар бере фокус на «Бачу — приглушити сирену». Аркуш від 900 px немодальний (`aria-modal="false"`). Закриття аркуша — крок «назад» в історії браузера, а не новий запис; «назад» під діалогом лише закриває діалог. Під час зміни мови підказка й сповіщення закриваються, `<html lang>` іде за мовою.
- **Широкі екрани.** Профілі `breed` (від 1800 px) і `ultrabreed` (від 2400 px) мають бічні зони від ядра: «дім у розрізі» й «Журнал наживо» (останні 8 записів) праворуч, а від 2400 px — три зони «план і кімнати | вміст | Журнал». Межі зон пересуваються мишею чи стрілками (ширини — `HV.opslag 'zone-breed'`); аркуш стає на місце правої зони. Свій вміст зони «план» розділ дає через `HV.zijzone('garage', ctx => html)` (компактний план чи мапа в `<section class="hv-zijkaart">`); без нього ядро показує розріз дому з посиланням на план або мапу. На полотні тоді є класи `heeft-zij` і `heeft-zij-links`.
- **Дрібне.** Небо «Дому» прокручується разом із героєм. Стрічки з гортанням (`hv-tabs`, `hv-held__chips`, `hv-scenes`, `hv-segment--rol`) самі ставлять активний пункт у поле зору й гасять край, за яким є ще вміст. `HV.huiszin(ctx).toon` має четверте значення `'alarm'`. У `HV.grafiek.toestanden` колонка назв доріжок — за найдовшим підписом (56–96 px, далі два рядки); підпис «зараз» не виходить за картку. «−/+» біля `o.schuif` ідуть кроком повзунка й позначені вимкненими на межі. У сітці `hv-tegels` дві плитки-рядки поруч із плиткою з керуванням загортайте в `<div class="hv-tegels__stapel">` (`HV.tegelMetBediening(a)` каже, чи плитка буде високою).

### 4.3. Запити й дозволи, «Уже так», запис Журналу, мова (коло 4)

- **Запит існує лише за «Питати».** Власник перемкнув дозвіл дії для виконавця (`HV.gevaar.zetStand`) — ядро само розбирає запити, що чекають (`HV.verzoekenNaStand(uitvoerder, sleutel, waarde)`): на «Вимкнено» вони знімаються (стан `verlopen`, `v.vervallen = { reden: 'stand-uit', tijd }`, запис «Запит знято: …» із причиною «дозвіл вимкнено», зникають із «Зараз важливо» й із черг); на «Завжди» — виконуються за новим дозволом (запис дії з «Дозволено правилом: дозвіл „Завжди“», `v.viaStand = 'altijd'`). Схвалити запит за «Вимкнено» неможливо з жодної кнопки: `HV.verzoek(id, true)` повертає `{ ok: false, reden: 'stand-uit' }` і знімає запит; `goedgekeurd: true` у `HV.doe` «Вимкнено» не перекриває. Якщо дозвіл став «Вимкнено» іншим шляхом (`zetStandStil`, строк рамок), запит знімається на наступному кадрі тим самим правилом. Свої картки запитів малюйте з `v.stand`: `wacht` · `bezig` · `goedgekeurd` · `afgewezen` · `verlopen` (знято — коли є `v.vervallen`). Сценарій, що сіє запит, сам ставить дозвіл: `HV.gevaar.zetStandStil(uitvoerder, sleutel, 'vragen')`. Той самий запит (виконавець, дія, ціль, значення) вдруге не створюється — `HV.doe` повертає `verzoek` наявного.
- **«Уже так / Is al zo».** Команда, що нічого не змінює (спостережене вже дорівнює бажаному), не пише запису й не дає «було → стало» з однаковими значеннями: `HV.doe` повертає `{ ok: true, ongewijzigd: true }`; людина бачить коротке сповіщення «Уже так» (і не проходить ритуал), виконавець без людини — нічого (за «Питати» запит не створюється; за «Вимкнено» спроба, як і раніше, лишає «Не виконано»). Це стосується лише станів, які ядро знає напевно (`aan`, `laden`, `open`, `vergrendeld`, `alarmstand`, `helderheid`, `kleurtemp`, `kleur`, `positie`, `kantel`, `doel`, `volume`, `programma`, `robot`, відомі слова `modus`/`stand`/`effect`/`ventilator`/`bron`, режим дому, ціль і світло кімнати, «усе світло»); власні можливості зон, разові команди, пристрій без зворотного зв'язку й сцена виконуються завжди. Якщо після `HV.doe` ви пишете власне сповіщення чи правите запис Журналу — робіть це лише коли `!r.ongewijzigd`.
- **«Повернути» — дія людини.** Відкат зі сповіщення виконує той, хто натиснув, а не виконавець дії: за «Питати» відкат дії агента не стає новим запитом.
- **Запис Журналу без дубля значення.** `o.bericht` показує назву й один чип зміни: `o.berichtKop(regel)` → `{ naam, delta }` (значення з кінця назви прибирається, коли поруч стоїть «було → стало»; однакові «було» й «стало» — не зміна, `delta === null`), `o.deltaChip(delta)` — сам чип. Для власної стрічки подій беріть їх, а не клейте `was + ' → ' + werd`.
- **Дім без минулого.** Сценарій із `w.logboekVanaf` (мить створення дому; так робить «Перший запуск») не має записів Журналу, датованих раніше: оболонка прибирає їх до й після кожного малювання (`HV.staat.snoeiLogboek()`), хай який модуль їх посіяв. Поле сценарію `zonderRegel: true` — запуск сценарію не пише свого запису.
- **Фокус у шарі** ставиться одразу після малювання шару (черга в `kern/lagen.js`), а не за таймером: запізнілий кадр більше не лишає фокус поза діалогом.
- **Мова.** Текст не можна обчислювати один раз: ні під час завантаження модуля (`var X = t(…)` на верхньому рівні, `HV.p`, `HV.woord.*`, `HV.meervoud`, `HV.datum` — теж), ні в кеші, ні в стані — він не перемкнеться з мовою. Зберігайте пару `[uk, nl]` і викликайте `t()`/`HV.p()` у `render`. Статична перевірка ловить виклик під час завантаження (файл:рядок; виняток — `taal-toegestaan.json` → `"laadtijdToegestaan": ["bestand:regel"]`), димова — кирилицю в нідерландському режимі на кожному маршруті, зокрема після перемикання uk → nl у тому самому сеансі. Свідомо український текст у нідерландському режимі (назва мови, поле «Назва українською») загортайте в елемент із `lang="uk"` — тільки його перевірка пропускає.

### 4.4. Ворота рішення, час запиту, зняття запиту, текст дії (коло 5)

Усе нижче додано до ядра без зміни наявних викликів: старі звернення працюють як раніше.

- **Рішення щодо запиту — лише через `HV.verzoek(id, ja, opties?)`; ворота стоять у ньому самому**, тож їх не оминає жодна кнопка («Зараз важливо», картка Журналу, черга агентів): зв'язок → **хто вирішує** (`HV.gevaar.magBeslissen(rol, niveau | actie)`: небезпечні й критичні — лише власник; звичайні й чутливі — власник або мешканець; дитина й гість — ніколи; відхилити може власник і мешканець) → чинний дозвіл → **ритуал рівня** (небезпечна дія — рейка, критична — рейка й підтвердження входу; «Уже так» — без ритуалу). Відмова ролі — сповіщення «Вирішує власник», `{ ok: false, reden: 'rol' }`, запит лишається `wacht`; скасований ритуал — `{ ok: false, reden: 'geannuleerd' }`. Власного `HV.schil.gevaar` перед `HV.verzoek` не викликайте — буде два ритуали. Рішення людини ядро пише окремим записом («Схвалено раз: …»), стан і підсумок запиту (`v.stand`, `v.uitkomst`: `uitgevoerd` · `alzo` · `niet`) ставить саме; запит без команди пристрою (`v.mcp`) воно теж закриває саме. `opties.naPoort(v)` викликається, коли всі ворота пройдено, перед виконанням (так «Помічник» записує «Схвалено до кінця дня»). У власній картці для ролі без права рішення замість кнопок покажіть рядок із замком («Вирішує власник»); `o.nu` робить це сам.
- **Схвалене дорівнює виконаному: час запиту.** Запит може назвати власний час виконання — поле `om` (час дому): «Зарядити авто о 02:00». Після «Схвалити раз» він не виконується одразу: стан `goedgekeurd`, `v.gepland = { om, tijd, wie }`, сповіщення «Схвалено: виконається о 02:00», а дію виконує годинник дому, коли настає `om` (запис дії з «схвалено раз: <хто схвалив>»). Перемикання дозволу на «Завжди» робить те саме (`v.viaStand = 'altijd'`, запис «Запит заплановано: …»). «Вимкнено» знімає й схвалений запит, що ще чекає свого часу.
- **Строк запиту називає лише сам запит.** Ядро строку не ставить: запит із `HV.doe` не має поля `tot`. Виконавець може назвати, доки запит має сенс: `HV.doe({ …, door, tot })` (кінець дешевого вікна) або поле `tot` у власному запиті сценарію. Коли цей час настає, ядро закриває запит: стан `verlopen`, `v.vervallen = { reden: 'tijd', tijd }`, запис «Запит минув: …». Рядка «час минув» біля живої кнопки не буває; для закритого запиту «Чекає до» не показуйте.
- **Запит, що втратив сенс, зникає.** Ядро щокадру знімає запит, що чекає, якщо пристрій уже напевно в цьому стані (`reden: 'alzo'`, запис «Запит знято: … / уже так: …»). Автор знімає власний запит сам: **`HV.verzoekIntrekken(id, [uk, nl])`** → `true`, якщо знято (стан `verlopen`, `v.vervallen = { reden: 'ingetrokken', tijd, tekst }`, запис «Запит знято: …» від імені автора; діє для запиту, що чекає, і для схваленого, який ще чекає свого часу). Так оптимізатор знімає запит на старт, коли кабель від'єднано чи план змінився, а сценарій «Вечір» — коли авто вже заряджене.
- **Стан запиту словами — `HV.verzoekWoord(v)` → `[uk, nl]`**: «чекає», «виконується», «схвалено · виконається о 02:00», «схвалено · виконано», «схвалено · уже так», «виконано за дозволом „Завжди“», «знято: дозвіл вимкнено», «знято: уже так», «знято: <причина автора>», «минув о 01:55», «відхилено». Беріть його для карток і списків «вирішено», а не власну таблицю за `v.stand`: знятий запит не «минув», а виконаний перемиканням на «Завжди» ніхто не «схвалював».
- **Текст запиту — зі значення.** `HV.actieZin(doel, mogelijkheid, waarde)` → `[uk, nl]`: «Почати зарядку авто» / «Зупинити зарядку авто», «Торшер: увімкнути», «Термостат: 20,5 °C», «Відімкнути двері: Замок вхідних дверей». Запит із `HV.doe` бере його сам (`v.wat`, рядок у «Зараз важливо», записи «Запит: …» і «Не виконано: …»). Власні слова дії — поле `doen(a, v)` у `kern/gevaar.js`. `HV.alZo(doel, mogelijkheid, waarde)` каже, чи команда нічого б не змінила.
- **«Уже так» — лише для стану, який дім знає напевно** (`beschikbaar === 'ok'`, без команди в дорозі): із застарілим чи припущеним станом і для сплячого пристрою команда йде завжди й лишає запис. Для власних можливостей зони перевіряйте самі (приклад — `doe` у `schermen/klimaat-media.js`: те саме значення → «Уже так» без `HV.doe`; разові команди — завжди дія).
- **Сповіщення без дубля значення.** `HV.meld({ titel:[uk,nl], was:[uk,nl], werd:[uk,nl], … })` — `o.toost` покаже назву без значення й один чип зміни (ті самі `o.berichtKop` і `o.deltaChip`, що в записі Журналу): «Торшер» і «55 % → 35 %», а не «Торшер: 35 %» і «55 % → 35 %». Не клейте `was + ' → ' + werd` у `tekst`.
- **Довга назва рівня** — готова пара `HV.gevaar.niveaus[n].lang` («небезпечна дія / gevaarlijke actie»); `o.risico(n, { lang: true })` бере її сам. Прикметник зі словом «дія / actie» не клейте: нідерландською він узгоджується.
- **«Завжди» і запити, що чекають.** `HV.verzoekenBijAltijd(uitvoerder, sleutel)` → `[uk, nl]` або `null`: що «Завжди» зробить із запитами, які зараз чекають. `o.stand` показує цей рядок під сегментами, а діалог підтвердження входу для небезпечної чи критичної дії — над кнопками (`HV.schil.herbevestig({ …, noot, altijdOpnieuw })`).

## 5. Робочий приклад

`schermen/energie-tarief.js` — замінює заглушку вкладки «Тариф»:

```js
(function (HV) {
  'use strict';
  var t = HV.t, h = HV.h, o = HV.o;
  function render(ctx) {
    var w = ctx.staat, nu = HV.tarief.prijs(w.tijd);
    var staven = HV.tarief.venster(w.tijd).map(function (x) {
      return { label: HV.tijd(x.tijd), waarde: x.prijs, toon: 'net-in', nu: w.tijd >= x.tijd && w.tijd < x.tijd + 3600000 };
    });
    return o.blok({ id: 'tarief', titel: t('Ціна на 48 годин', 'Prijs voor 48 uur'), inhoud:
      o.kaart({ inhoud: o.getal({ maat: 'l', label: t('Зараз', 'Nu'), waarde: HV.euro(nu), sub: h(t('за кВт·год · приклад', 'per kWh · voorbeeld')) }) +
        HV.grafiek.staven({ id: 'tarief48', titel: t('Ціна за годинами', 'Prijs per uur'), eenheid: '€', decimalen: 2, tikken: 6, staven: staven,
          samenvatting: t('Від’ємна ціна стоїть під нулем.', 'Een negatieve prijs staat onder de nul.') }) +
        o.knop({ tekst: t('Заряджати авто зараз', 'De auto nu laden'), actie: 'tarief-laad' }) }) });
  }
  HV.tab('energie', { id: 'tarief', titel: ['Тариф', 'Tarief'], adres: '/energie/tarief', render: render });
  HV.actie('tarief-laad', function () { HV.doe({ doel: 'laadpaal', mogelijkheid: 'laden', waarde: true }); });
})(window.HV = window.HV || {});
```

## 6. Іконки

Іконка lucide (ISC) додається сама: достатньо вжити її назву kebab-case як рядок — `HV.icoon('sun')` чи `icoon: 'sun'`; складальник вшиває символ. Власний знак — запис у `HV.eigenIconen` (`kern/onderdelen.js`). Емодзі немає ніде.

## 7. Збірка й перевірка

```
node scripts/huis-maquette.mjs                      # docs/huis/maquette/huis-maquette.html
node scripts/huis-maquette.mjs --artefact <шлях>    # варіант «лише вміст» для сторінки-артефакта
node scripts/huis-maquette.mjs --controle           # статичні перевірки (код завершення 1 при помилках)
node scripts/huis-maquette-rook.mjs --uit <тека>    # димова перевірка в браузері; --snel — скорочений обхід
```

Статична перевірка: унікальні `id`; кожен пункт навігації має екран; кожна пара `t()` має обидві мови; мовний закон; жодного мовозалежного виклику (`t`, `p`, `meervoud`, `telwoord`, `datum`, `datumKort`) під час завантаження модуля; жодного кольору в CSS поза блоком токенів і жодного `@media` за шириною; `font-weight` лише 400/500/600/700 або токен; текст не менший за 12 px; `--muted`/`--faint` не стоїть у селекторах неба; кожна небезпечна й критична дія має текст наслідку.
Димова: усі маршрути × 6 профілів × 3 теми × 2 мови — помилки консолі, горизонтальне прокручування, цілі ≥ 44 px, обробники `data-actie`, у нідерландському режимі — жодної кирилиці поза `lang="uk"`; перемикання мови uk → nl на всіх маршрутах; клікпроба лампи, повзунка, сцени, режиму, сценарію, рейки утримання, дозволів і запитів («Вимкнено» знімає, «Завжди» виконує; запит із власним часом виконується у свій час і «минає» у свій строк; гість не схвалює, власник схвалює критичне лише рейкою), «Уже так», порожнього Журналу «Першого запуску» й аварійного шару.

## 8. Правила тексту й стилю

- Тексти інтерфейсу — завжди парою `t('українська', 'nederlands')`; у даних — `[uk, nl]`. В українських рядках латиниця лише з дозволеного переліку (`taal-toegestaan.json` доповнює перелік із `tests/eenheid/hulp/taalcontrole.ts`).
- У CSS — лише `var(--…)` і класи `hv-`; адаптивність — `@container doek (…)`, не `@media`; замість `svh` — `cqh`.
- Усе з числами лежить на папері (`--panel`); скло — лише шапка, навігація, оболонка аркушів і Команда; на небі — тільки `--text` (`--muted` — лише на склі й папері).
- Ціль дотику ≥ 44 px (`--hv-tik`); кожна дія з наслідком має підказку `o.gevolg(…)`: «Що станеться · Пов'язано з · Як повернути».
- Без `alert/confirm/prompt`, без зовнішніх адрес, `localStorage` — лише через `HV.opslag`.
