# Зона 8. ШІ-помічник, агенти, ролі / Assistent en agenten

Задача HUIS-001 · етап 0 · 10.11.2026 · статус: на погодженні власника

Джерела: план HUIS-001 (§1, §3, §3.8, §4) і [дизайн-мова «Живий дім»](../ДИЗАЙН-МОВА-ЖИВИЙ-ДІМ-20261110.uk.md) (далі — ДМ). Назви токенів, компонентів, станів і профілів — з ДМ; граматика адрес — із зони [«Каркас»](01-КАРКАС.uk.md); нові компоненти — §16.

## 0. Що змінилося

- **«Живий дім».** Зона стоїть на тихому небі розділу «Автоматика / Automatisering»: на небі — лише речення й заголовки блоків `--text`; розмова, черга, таблиці, картки — на папері `--panel`; скло `--hv-glas` — шапка, навігація, оболонка аркушів і «Команда / Opdracht». Заборони скла, неба й градієнтів знято.
- **Дозволи** (план §3.8). Кожна дія має `hv-stand` «Вимкнено / Uit · Питати / Vragen · Завжди / Altijd» окремо для кожного виконавця, зокрема кожного агента й вбудованого «Помічника дому»; типово «Вимкнено»; власник може обрати будь-який режим. Прибрано: стелі, «щонайбільше Питати», сірі сегменти, заборони Ж1–Ж6, години 07:00–23:00 і 60 дій на добу як типові, строк «до 30 днів», примусове «Питати» після чужого тексту, «лише читання під час тривоги», самочинну паузу агента. Це тепер **необов'язкові рамки**, які вмикає власник.
- **Лишилося:** ритуал людини (рейка, особистий код на панелі, підтвердження входу), обов'язковий Журнал, жодного інструмента зміни дозволів.
- **Звірено з ДМ:** знак рівня `hv-risico` (чутлива — `Eye`); «змішано / gemengd»; `hv-verzoek` — «Схвалити раз / Eén keer goedkeuren» без нав'язаного строку; `hv-voorstel` — «було → стане / was → wordt»; види сповіщень `huis.agent` і `huis.toegang`; `hv-gevaar` за адресою не відкривається; параметр `tab` зарезервовано — вкладки агента йдуть через `deel`.
- **Етапи** — шкала 0–12 (§17). **Повнота:** повний набір інструментів агентів для всіх класів пристроїв (§7).

## 1. Задум і межі

Зона відповідає: що в домі робить ШІ, хто це дозволив і як це зупинити.

- **Помічник дому / Huisassistent** — вбудований агент із тим самим стовпцем дозволів, що й зовнішні, без прихованих прав.
- **Зовнішні агенти** під'єднуються через групу `huis` з'єднувача (MCP). Сторінка платформи `mcp.tarasevych.com/agenten` вмикає лише саму групу; режими дій живуть у матриці дому й там показані для читання з посиланням.
- **Розмова не обходить ритуал.** Дія, яку людина підтвердила кнопкою в картці помічника, — дія людини з ритуалом її рівня й автором `User`. Дозвіл Помічника стосується лише того, що він робить сам.
- **Межі.** Матриця `/instellingen/toestemmingen` і реєстр `/instellingen/risico` — спільні сторінки Системи, зона дає їм стовпці агентів; редактор правил — «Автоматика»; ключі й сеанси — `id.tarasevych.com`.
- **Підтвердження входу** сьогодні діє 5 хв на сеанс (`STAP_OP_MS`); до одноразового (план §7) діалоги кажуть: «Підтвердження діє 5 хв для цього сеансу / De bevestiging geldt 5 min voor deze sessie».

## 2. Вигляд

- **Герой** ≤ ¼ екрана на телефоні, стискається в рядок шапки. Речення — лише спостережене: «Claude чекає на ваше рішення; Помічник виконав 6 дій / Claude wacht op je besluit; de Assistent voerde 6 acties uit». Під ним паперові чипи 28 px: «2 запити / 2 verzoeken», «! 1».
- **Автор** — `hv-maker` «ШІ-агент / AI-agent» (квадрат зі зрізаним кутом, 12 px) з іменем. Логотип бренду з `src/merk/` — лише в `hv-agentkaart` справді під'єднаного агента; у симуляції — знак і ім'я. Вкладка «Що бачить агент» іконки «око» не має: `Eye` означає лише чутливий рівень.
- **«!»** — кнопка 24 px біля `hv-stand` небезпечної й критичної дії; за «Завжди» — постійна залита позначка `--hv-risico-merk` (на місці кнопки, у лівому верхньому куті плитки, у шапці «! N» з переходом у `/instellingen/risico`), закрити її не можна.
- **Плитка під керуванням агента** — знак автора 10 хв після зміни, стани «очікує / wacht» і «виконується / bezig». Знак із ритуалом на плитці стосується людини; агент за «Завжди» діє без рейки.
- **Акцент** — лише одна основна кнопка («Схвалити раз» у запиті).

## 4. Помічник `/assistent`

```
┌ Помічник    ● готовий    ◩ 2 ┐   телефон 390
│ [Чекає 2][Підсумок][Ще]      │
│ Ви: вимкни світло внизу      │
│ ◩ Я зрозумів це як: перший   │
│   поверх, світло [Виправити] │
│ ┌ Пропозиція · 5 ламп ─────┐ │
│ │ Торшер   увімкн. → вимкн.│ │
│ │ Гараж    недоступний     │ │
│ │ [Виконати] [Змінити]     │ │
│ │ [Відхилити]              │ │
│ └ джерела: стан · 2 с ─────┘ │
│ [кімната: Вітальня ✕][Запит…]│
└──────────────────────────────┘
```

Комп'ютер (`bureau`): ліворуч розмова `hv-gesprek` з підсумком дня вгорі, праворуч паперові блоки «Чекає на вас / Wacht op jou», «Пропозиції / Suggesties», «Незвичне / Ongewoon».

- **Команда → дія.** Картку `hv-voorstel` малює сервер із сухого прогону — того самого, що в `hv-opdracht` і `/api/huis/gevolg`. Далі за режимом Помічника для цієї дії: «Завжди» — виконує сам, знак автора, `hv-toost` із «Повернути / Ongedaan maken» 10 с; «Питати» чи «Вимкнено» — кнопка «Виконати / Uitvoeren» для людини з ритуалом її рівня (небезпечне й критичне — `hv-gevaar`). За «Вимкнено» під карткою: «Помічник цього сам не робить; ви можете виконати / De Assistent doet dit niet zelf; jij kunt het uitvoeren».
- **Опис → автоматизація.** Чернетка в редакторі «Автоматики» з переказом і оцінкою «спрацювало б 14 разів за 30 днів / zou 14 keer zijn afgegaan in 30 dagen»; правило починає як «Чернетка / Concept», увімкнення — окрема дія з власним `hv-stand`.
- **Запитання до дому** — текст, живі плитки або `hv-grafiek` із чипами джерел `hv-bron`; без джерела числа немає.
- **«Чому це сталося»** — `hv-waarom` «Що запустило / Aanleiding → Умова / Voorwaarde → Дія / Actie» з Журналу, без моделі; вхід із розмови, аркуша пристрою й Журналу.
- **Уточнення** — `hv-chip--keuze`; **контекст** — `hv-chip--context`; **змішана мова й латинка** — «Я зрозумів це як… / Ik begreep dit als…» з «Виправити / Corrigeren».
- **Підсумок дня / Dagoverzicht** о 07:30 і 21:30 — шаблоном без ШІ. **Пропозиції** — доказ і «Створити / Maken · Не зараз / Niet nu · Ніколи / Nooit». **Незвичне** — графік і «Це нормально / Dit is normaal».
- **Голос** — штамп «пізніше / later» до рішення про мікрофон (план §7). Голос — дія людини: небезпечне й критичне відкриває `hv-gevaar` на екрані, бо рейку голосом не утримати.
- **Стани:** «готовий / gereed · думає / denkt na · чекає вашого рішення / wacht op je besluit · бюджет вичерпано / budget op · недоступний / niet bereikbaar · лише перегляд / alleen bekijken». Недоступний Помічник нічого не блокує: Команда, сцени й «Чому це сталося» працюють без нього.

## 5. Агенти й погодження `/automatiseringen/agenten`

```
 небо · Автоматика › Агенти          [Зупинити самостійні дії] [+ Додати агента]
┌ Агенти ─────────┐ ┌ ◩ Claude · працює · 14 дій сьогодні         [Призупинити] ┐
│ ◩ Помічник дому │ │ Інструменти · [Рамки] · Дії · Що бачить агент             │
│ ◩ Claude     !  │ │ Рамки: без рамок                         [Змінити рамки]  │
│ ◩ Gemini        │ │ ▾ Світло й розетки · 31 дія · Завжди: 0                   │
│   призупинено   │ │   Для всієї групи                 змішано                 │
├ Зараз працює ───┤ │   Увімкнути світло          [Вимкнено][✓Питати][Завжди] i │
│ Claude: зарядка │ │ ▾ Замки й охорона · 8 дій · Завжди: 1                     │
│ виконується Стоп│ │   Відімкнути двері ⬣! крит. [Вимкнено][Питати][✓Завжди]   │
└─────────────────┘ │   Зняти охорону   [!] крит. [✓Вимкнено][Питати][Завжди]   │
                    └───────────────────────────────────────────────────────────┘
```

Телефон: черга → картки `hv-agentkaart` → сторінка агента; у «Рамках» назва дії, `hv-risico` і «!» — першим рядком, `hv-stand` на всю ширину — другим.

- **`hv-agentkaart`:** знак, ім'я, стан, лічильник дій, «!» за «Завжди» на небезпечній чи критичній дії, «Призупинити / Pauzeren» ↔ «Відновити / Hervatten». Органа зміни дозволів немає.
- **Інструменти** (`hv-gereedschaplijst`) — групи §7 з описом, рівнями й чинним режимом словом. Сірого рядка «недоступно» немає.
- **Рамки** — як велить ДМ §10, тут власник змінює дозволи: `hv-stand` кожної дії, груповий орган «Для всієї групи / Voor de hele groep», лічильник «Завжди: N / Altijd: N», над ними рамки (§6). Іншим ролям — режим текстом і «Змінює лише власник / Alleen de eigenaar kan dit wijzigen».
- **Дії** — `hv-bericht`: що · слова агента · «було → стало / was → werd» · «дозволено через / toegestaan via» · результат · модель; «Повернути все / Alles ongedaan maken» для запуску, де відкат можливий.
- **«Зараз працює / Nu bezig»** — `hv-agentstappen`: кроки запуску зі станами команди й «Стоп / Stop» (зупиняє запуск, режимів не змінює).
- **Майстер «Додати агента»** (`hv-gids`, лише власник): хто → початковий набір → рамки → з'єднання (адреса, згода OAuth) → пробний виклик у симуляції → підсумок. Набори — лише стартовий вибір власника: «Усе вимкнено / Alles uit» (типово) · «Лише читання / Alleen lezen» · «Помічник / Assistent» (читання — «Завжди», звичайне й чутливе керування — «Питати», решта — «Вимкнено», рамка «Після чужого тексту — питати»). Будь-яке «Завжди» для небезпечного чи критичного в підсумку — одне підтвердження входу з переліком дій.

## 6. Дозволи агентів

- **Дозвіл належить дії** («можливість × напрям × пристрій або клас»), а не інструменту: один виклик із кількома діями проходить ворота для кожної.
- **«Вимкнено»** — дія агентові не оголошується; виклик дає «не виконано / niet uitgevoerd» з назвою воріт. **«Питати»** — запит `hv-verzoek` (§8). **«Завжди»** — виконується в рамках власника, зі знаком автора, `hv-toost` і записом Журналу.
- **Ворота на сервері** (каркас §7): джерело («лише читання / alleen-lezen») → роль людини, від імені якої діє агент (власника, що його додав) → пауза → режим → рамки. Рівень ризику агента не зупиняє — він лише задає ритуал людині.
- **Змінює лише власник** на особистому пристрої з підтвердженням входу платформи для «Завжди» небезпечного й критичного; на `/paneel/*` і `tv` — режим текстом. Агент не може ні розширити, ні звузити права — ні свої, ні чужі.
- **Рамки — необов'язкові, типово «без рамок / zonder kaders»:** строк, кімнати, години, бюджет дій, а також «Після чужого тексту — питати / Na vreemde tekst vragen», «Під час тривоги — лише читання / Tijdens alarm alleen lezen», «Хто отримує запити / Wie krijgt verzoeken» (типово — усі власники). Минув строк — режим повертається до «Вимкнено» з чипом «строк минув / termijn verlopen».
- **Журнал обов'язковий:** кожна зміна дозволу й кожна дія за ним — `hv-bericht` і `hv-meldingen`; аудит лише на додавання; вимкнути це не може ніхто.

## 7. Повний набір інструментів

Група `huis` з'єднувача (етап 5), кожна дія — під своїм `hv-stand`, типово «Вимкнено». Рівні — приклади з матриці `shared/huis-gevaar.ts` (етап 2).

**Таблиця — єдиний реєстр назв інструментів**; групи — ті самі, що в `hv-gereedschaplijst`. Макет показує всі назви, крім позначених «поза макетом»: ті з'являються на своїх етапах (§17). Зони [«Гараж»](06-ГАРАЖ.uk.md) §10 і [«Автоматика»](07-АВТОМАТИКА.uk.md) §10 додають інструменти свого розділу; для дії, що є в цій таблиці, чинна назва звідси. ## 8. Черга «Чекає на вас / Wacht op jou»

`hv-verzoek` із тілом `hv-voorstel`: «Хто / Wie · Що / Wat · Чому / Waarom · Чекає до / Wacht tot»; знак рівня, склад «було → стане» (кілька кроків — одна картка й одна транзакція), «Слова агента / Woorden van de agent» з `hv-chip--wantrouw`, якщо в них є чужий текст. «Чекає до» називає сам запит (наприклад, початок дешевого вікна) або рамка власника; система строку не нав'язує.

```
┌ Чекає на вас · 1 ────────────┐   телефон, аркуш ?blad=verzoek:<id>
│ ◩ Claude · 3 хв тому         │
│ Зарядити авто о 02:00        │
│ чутлива · Чекає до 01:55     │
│ було → стане                 │
│  Зарядка  пауза → 02:00–05:10│
│  Ціль     64 % → 80 %        │
│ Чому: о 02:00 € 0,08/кВт·год │
│ Слова агента · чужого тексту │
│ немає                        │
│ [Відхилити]                  │
│               [Схвалити раз] │
└──────────────────────────────┘
```

- **Відповіді:** «Схвалити раз / Eén keer goedkeuren» і «Відхилити / Afwijzen». Схвалення — дія людини з правами її ролі й ритуалом рівня: звичайне — одразу; чутливе — з «Повернути» 10 с; небезпечне — рейка; критичне — рейка й підтвердження входу; на панелі — особистий код. Типово небезпечне й критичне схвалює лише власник, звичайне й чутливе — власник або мешканець; це коло власник змінює рамкою «Хто отримує запити». Дитина й гість не схвалюють: замість кнопок вони бачать рядок із замком «Вирішує власник / De eigenaar beslist». Правило одне для кожної кнопки — «Зараз важливо», картка Журналу, сторінка агентів; рішення людини пишеться в Журнал окремим записом «Схвалено раз / Eén keer goedgekeurd» або «Відхилено запит / Verzoek afgewezen».
- **Хто отримує:** люди з рамки «Хто отримує запити»; у сповіщенні на пристрій звичайне й чутливе можна схвалити одразу, небезпечне й критичне — лише «Відкрити / Openen». Відповідь людини в розмові з агентом схваленням не є: схвалюють лише в хабі.
- **Після 10 однакових схвалень** власник бачить рядок «Ви схвалили це 10 разів / Je hebt dit 10 keer goedgekeurd» із посиланням на `hv-stand` цієї дії — без підказки, який режим обрати.
- **Стани:** «чекає / wacht · схвалено / goedgekeurd · відхилено / afgewezen · минув / verlopen · виконано / uitgevoerd · не виконано / niet uitgevoerd»; до них — «схвалено · виконається о 02:00 / goedgekeurd · wordt om 02:00 uitgevoerd» (запит із власним часом виконання: схвалення не запускає дію одразу, її виконує годинник дому) і «знято / vervallen» з причиною: «дозвіл вимкнено / toestemming uitgezet» (власник перемкнув дію цього виконавця на «Вимкнено»; на «Завжди» запит, що чекав, виконується за новим дозволом — дизайн-мова, §10), «уже так / was al zo» (пристрій уже в цьому стані) або словами автора запиту, коли той сам його зняв, бо запит утратив сенс. «Минув» буває лише після строку, який назвав сам запит. Одна дія одного виконавця має щонайбільше один запит, що чекає; дія, яка нічого не змінює, запиту не створює, а людині відповідає «Уже так / Is al zo» без запису в Журналі.

## 9. Пауза, Журнал, сповіщення

- **«Зупинити самостійні дії / Zelfstandige acties stoppen»** (`?dialoog=stoppen`, аварійний шар, Система) — прапорці «автоматизації · оптимізатор · агенти». Режимів не змінює; зупиняє власник або мешканець, на `hv-nood` — кожен; відновлює лише власник. Агент себе не призупиняє й не відновлює. Незвична частота дій агента дає сповіщення з кнопкою «Призупинити», а не самочинну паузу.
- **`huis.agent`** — кожна дія агента й кожен запит. **`huis.toegang`** («Доступ до дому / Toegang tot het huis», важливість «важливо», не приглушується, усім власникам): агента під'єднано чи від'єднано, змінено його рамки, чужий текст додається до знімка; нова людина, зміна ролі, гостьовий код; перенесення із симуляції. Зміна дозволу `hv-stand` — `huis.systeem`: до відома, а «Завжди» для небезпечної чи критичної дії — важливо; пауза й відновлення самостійних дій — `huis.systeem`, важливо. Єдина таблиця «подія → вид → важливість» — [«Архітектура»](09-АРХІТЕКТУРА.uk.md) §10. Кожна картка `huis.toegang` і картка «Завжди» для небезпечної чи критичної дії має «Це не я / Dat was ik niet»: зупинити самостійні дії, від'єднати агента, відкликати запрошення чи код, вийти всюди (`id.tarasevych.com`).

## 10. Чужий текст і дані назовні

- **Чужий текст** — усе, що написала не людина з роллю в домі: назви треків, імена клієнтів мережі, події камер, календар, назви місій, слова іншого агента. Він може містити сховані вказівки, тож типово не входить у знімок для агента.
- **«Що бачить агент»** (`hv-gezien`): знімок, секрети як «••••», «Вилучено: 14 назв треків… / Weggelaten: 14 tracktitels…» з перемикачем «Додавати / Meesturen» на кожен тип (типово вимкнено, з «!»).
- **Хмарна модель:** перед першим надсиланням і за кожного нового типу даних — аркуш «Що буде надіслано». Точна присутність, місце й кадри камер — окремі типи з власним перемикачем власника.

## 11. Люди, ролі, приватність

| Область | Власник / Eigenaar | Мешканець / Bewoner | Дитина / Kind | Гість / Gast |
|---|---|---|---|---|
| Світло, клімат, медіа, сцени | усе | усе | свої кімнати, дозволені сцени | вибрані кімнати й сцени |
| Енергія, гараж, камери | усе | бачить і керує | бачить енергію | — |
| Замки, охорона | ритуал рівня | ритуал рівня | — | двері за розкладом |
| Дозволи `hv-stand`, агенти | змінює | бачить текстом | — | — |
| Запити агентів | схвалює | схвалює, якщо його додано до «Хто отримує запити» | — | — |

- **Запрошення** (`?dialoog=uitnodigen`): хто → роль → кімнати → строк і «Що побачить Марта / Wat Marta ziet». Сторінка людини — роль, кімнати, строк `hv-aftel`, згоди, посилання на сеанси в `id.tarasevych.com`. Останнього власника вилучити не можна. `installateur` і `ondersteuning` — технічні ролі без схвалень і дозволів.
- **Приватність:** «Мої дані / Mijn gegevens» (згоди, «Експортувати / Exporteren», «Видалити / Verwijderen», «Хто дивився мої дані / Wie keek naar mijn gegevens»), «Куди йдуть дані / Waar gegevens heen gaan» (`hv-grafiek--stroom` без руху), «Приватна кімната / Privékamer» — її не бачать інші ролі й агенти.

## 12. Симуляція й справжня оселя

Дозволи, рамки й увімкнені автоматизації належать оселі. Справжня починається з «Вимкнено» всюди; перенесення — майстер `?dialoog=overnemen`: пункти зняті, власник позначає потрібні, усі «Завжди» небезпечних і критичних дій — одне підтвердження входу з переліком. Особисті коди й коди панелей не переносяться: це секрети людей. Сценарії симулятора: «Агент просить схвалення / Agent vraagt goedkeuring», «Вказівки в назві треку / Instructies in een tracktitel», «Агент вичерпав бюджет / Agent heeft budget op».

## 13. Профілі екранів

`wand` — черга й «Схвалити раз» з особистим кодом; `tv` — черга для перегляду, критичне — «Підтвердьте на телефоні / Bevestig op je telefoon»; `horloge` — обличчя `verzoek` з «Відхилити» й «Відкрити на телефоні / Openen op je telefoon»; `strook` — «N запитів агентів» у зоні винятків; `inkt` — підсумок дня. Дозволи змінюються лише на особистих пристроях власника.

## 14. Підказки

Обчислювані тексти — `/api/huis/gevolg`, шаблони — `tekst.ts`.

- **`hv-stand` світла, «Завжди».** «Що станеться: Claude вмикатиме й вимикатиме світло без запиту. Пов'язано з: кожна дія має запис у Журналі з „Повернути“. Як повернути: „Питати“ — діє одразу.» / «Wat er gebeurt: Claude zet het licht aan en uit zonder te vragen. Hangt samen met: elke actie staat in het logboek met ‘Ongedaan maken’. Terugdraaien: ‘Vragen’ — werkt direct.»
- **«!» — відмикання дверей, «Завжди».** «Що може статися: двері відімкнуться, коли нікого немає вдома. Пов'язано з: агент читає чужий текст, що може містити сховані вказівки. Як повернути: „Замкнути“. Хто зможе це запускати: Claude сам, без вашого схвалення. Як вимкнути: „Вимкнено“ тут або „Зупинити самостійні дії“.» / «Wat er kan gebeuren: de deur gaat van het slot terwijl niemand thuis is. Hangt samen met: de agent leest vreemde tekst die verborgen instructies kan bevatten. Terugdraaien: ‘Vergrendelen’. Wie dit kan starten: Claude zelf, zonder je goedkeuring. Uitzetten: ‘Uit’ hier of ‘Zelfstandige acties stoppen’.»
- **Відмова агентові за «Вимкнено»** (запис у «Діях»). «Чому ні: дозвіл „Вимкнути все в домі“ для Claude — „Вимкнено“. Що перевірити: рамки й режим у вкладці „Рамки“. Що можна натомість: виконати власноруч через Команду.» / «Waarom niet: de toestemming ‘Alles in huis uit’ staat voor Claude op ‘Uit’. Wat te controleren: kaders en stand op het tabblad ‘Kaders’. Wat wel kan: zelf uitvoeren via Opdracht.»
- **Запит, що минув.** «Що станеться: дію не виконано, запис лишається в Журналі. Пов'язано з: дешеве вікно почалося о 02:00. Як повернути: попросіть агента подати запит знову.» / «Wat er gebeurt: de actie is niet uitgevoerd, de vermelding blijft in het logboek. Hangt samen met: het goedkope venster begon om 02:00. Terugdraaien: vraag de agent het verzoek opnieuw in te dienen.»

## 15. Стани

Спільні дванадцять (ДМ §9), стани `hv-stand` (десять), `hv-verzoek`, `hv-agentkaart` («працює / actief · призупинено / gepauzeerd»). **До ДМ:** агент — «не під'єднано / niet gekoppeld · виконується / bezig»; `hv-voorstel` — «виконується / bezig · виконано / uitgevoerd · не виконано / niet uitgevoerd · повернуто / ongedaan gemaakt»; помічник — шість станів §4.

## 18. Рішення для власника

1. **Одноразове підтвердження входу** (план §7) замість 5 хв на сеанс.
2. **Мікрофон у браузері** (план §7): без нього голос — лише окремими пристроями.
3. **Модель Помічника дому:** локальна, хмарна чи обидві; місячний бюджет.
4. **Згода інших дорослих** (AVG) на передавання їхньої точної присутності, місця й кадрів хмарній моделі — потрібна на додачу до дозволу власника чи ні.
5. **Дитина:** роль `kind` (зміна обмеження в `huis_leden`), чи користується вона помічником і чи зберігається її розмова.
6. **Гість:** лише з обліковим записом платформи чи також за посиланням із кодом.
