# Cloud Database Schema — v1

All records are private by default and owner-scoped. Database IDs are generated by the platform.

## `cloud_workspaces_v1`

| Field | Type | Rule |
|---|---|---|
| `ownerUserId` | string | mandatory tenant boundary |
| `title` | string | 2–100 chars |
| `normalizedTitle` | string | NFKC + lowercase; owner-local uniqueness |
| `description` | string | up to 500 chars |
| `template` | enum | `project`, `documentation`, `meeting`, `personal` |
| `sections` | array | stable shallow visual anchors; not folders |
| `status` | enum | `active`, `archived` |
| `createdAt`, `updatedAt` | epoch ms | server-owned |
| `archivedAt` | epoch ms | `0` while active |

Indexes/query keys required conceptually:

- `(ownerUserId, status)`;
- `(ownerUserId, normalizedTitle)`.

## `cloud_items_v1`

| Field | Type | Rule |
|---|---|---|
| `ownerUserId` | string | mandatory tenant boundary |
| `workspaceId` | string | empty means Quick Capture |
| `suggestedWorkspaceId` | string | existing owner workspace only |
| `kind` | enum | `file`, `note`, `link` |
| `title` | string | AI or deterministic fallback, max 120 |
| `originalName` | string | file source label only |
| `description` | string | max 500 |
| `textContent` | string | note content, max 50k |
| `sourceUrl` | string | normalized HTTP(S) URL |
| `mimeType` | string | server-validated safe type |
| `sizeBytes` | number | decoded bytes |
| `storagePath` | string | server-generated, never public |
| `tags`, `people` | string[] | bounded and de-duplicated |
| `status` | enum | `captured`, `waiting_review`, `in_progress`, `done` |
| `aiState` | enum | `suggested`, `fallback` |
| `aiConfidence` | number | clamped 0–1 |
| `createdAt`, `updatedAt`, `openedAt` | epoch ms | server-owned |

Indexes/query keys required conceptually:

- `(ownerUserId, updatedAt)`;
- `(ownerUserId, workspaceId)`;
- `(ownerUserId, status)`.

## `cloud_resume_v1`

One effective latest record per owner.

| Field | Type |
|---|---|
| `ownerUserId` | string |
| `currentWorkspaceId` | string |
| `currentItemId` | string |
| `focus` | boolean |
| `energy` | `low`, `medium`, `high` |
| `updatedAt` | epoch ms |

## `cloud_ai_decisions_v1`

Stores bounded evidence without duplicating raw item content.

| Field | Type |
|---|---|
| `ownerUserId` | string |
| `itemId` | string |
| `inputFingerprint` | SHA-256 hex |
| `state` | `suggested`, `fallback` |
| `reasonCode` | string |
| `confidence` | number |
| `suggestedWorkspaceId` | string |
| `createdAt` | epoch ms |

## `cloud_audit_v1`

| Field | Type |
|---|---|
| `ownerUserId` | string |
| `action` | namespaced string |
| `entityType` | `workspace`, `item`, future provider/share types |
| `entityId` | string |
| `details` | non-secret bounded metadata |
| `createdAt` | epoch ms |

Initial actions:

- `cloud.workspace.created`;
- `cloud.item.captured`;
- `cloud.item.placed`;
- `cloud.item.status.changed`.

## Future tables (not runtime-active)

- `cloud_jobs_v1` — leased idempotent worker queue;
- `cloud_content_chunks_v1` — extracted content chunks and fingerprints;
- `cloud_search_documents_v1` — hybrid index documents;
- `cloud_provider_accounts_v1` — owner/provider account state;
- `cloud_oauth_tokens_v1` — encrypted refresh-token envelopes;
- `cloud_sync_state_v1` — provider cursor/delta state;
- `cloud_provider_items_v1` — external object projections;
- `cloud_shares_v1` — short-lived, revocable and scope-bound sharing;
- `cloud_item_links_v1` — linked captures / relationship graph;
- `cloud_reminders_v1` — soft check-ins with user-controlled cadence.
