# Universal Файл Workspace · Mijn Ruimte

Це **локальний початковий інтеграційний пакет**, а не латка робоче середовище-репозиторію.

**Вміст:** `src/contracts.ts` (модель), `src/sniff.ts` (magic/ZIP manifest), `src/registry.ts` (adapters/engines/ACL), `src/default-engines.ts` (manifest кандидатів), `test/` (6 Node-тестів), `docs/` (аудит і план міграції), `demo/index.html` (самостійний адаптивний демо-інтерфейс).

## Перевірка

```sh
npm test
```

Потребує локально встановлених Node.js 22+ і TypeScript (`tsc`). У стартовому пакеті немає мережевих залежностей. Демо — це статичний HTML/JS/CSS лише з локальним відкриттям файлів; усі мітки мережевих джерел є демонстраційними.

## Не заявлено як виконане

Поточний робоче середовище-код не змінено, поточний Git-фіксація змін не перевірено, реальні перехідники OAuth/Drive/Gmail/GitHub ще не під'єднано, серверних конвертацій і криптографічної перевірки коректності немає. `proposedEngines` — маніфести майбутніх інтеграцій; їхні фактичні пакети не входять у цей стартовий набір. До увімкнення в робоче середовище потрібна реальна інтеграція, тести та перевірка безпеки.

## Базовий пріоритет

Повторне використання наявних переглядач-функцій перед їх заміною. Спочатку ядро лише для читання та міграція споживачів, потім повноцінні налаштування рушіїв, завдання запису/конвертації та редактори документів.
